# 📚 Polytechnic Hub

**Polytechnic Hub** is a native Android educational application designed for Polytechnic/Diploma engineering students.

The app provides study materials, notes, previous year questions, quizzes, subjects, and other useful academic resources in one place.

---

## 🎯 Purpose

The main purpose of Polytechnic Hub is to make Polytechnic/Diploma study resources easily accessible from a single Android application.

Students can use the app to:

- 📖 Read study notes
- 📚 Access subject-wise materials
- 📝 Practice MCQ questions
- 📄 View PDF notes
- 🧠 Take quizzes
- 📋 Practice Previous Year Questions (PYQ)
- 📊 Track learning progress
- 🎓 Access semester-wise content

---

## 🚀 Main Features

- 🏠 Modern Home Dashboard

## 🎓 Supported Branches

Polytechnic Hub is designed to support multiple Diploma engineering branches:

- ⚡ Electrical Engineering
- 🏗️ Civil Engineering
- ⚙️ Mechanical Engineering
- 💻 Computer Science Engineering
- 📡 Electronics Engineering
- 🚗 Automobile Engineering
